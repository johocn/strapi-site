## 1. 系统概述

### 1.1 系统架构

本系统是基于 Strapi + UniApp 构建的多租户管理后台，主要功能模块包括：

```
后台管理系统
├── 多租户管理 — 创建/编辑/删除租户，配置站点信息
├── 渠道管理 — 渠道树结构，成员管理，邀请码
├── 课程管理 — 课程/课时/分类/标签/知识点管理
├── 题库管理 — 题目管理，答题记录，考试管理
├── 积分管理 — 积分类型/规则/记录/兑换管理
├── 系统管理 — 用户/角色/权限/日志管理
├── 媒体管理 — 文件上传，图片库管理
├── 第三方配置 — 微信登录/分享配置
└── 仪表盘 — 数据统计概览
```

### 1.2 浏览器要求

| 浏览器 | 最低版本 | 说明 |
|--------|----------|------|
| Chrome | 90+ | 推荐 |
| Firefox | 88+ | |
| Edge | 90+ | |

### 1.3 访问地址

- **开发环境**：http://localhost:1337/admin
- **生产环境**：http://你的域名/admin

## 2. 登录与权限

### 2.1 登录流程

1. 打开浏览器，访问后台地址
2. 在登录页面输入用户名和密码
3. 点击「登录」按钮

**默认账号**：
- 用户名：admin
- 密码：首次启动时设置

### 2.2 角色体系

| 角色 | 权限范围 | 适用场景 |
|------|----------|----------|
| super-admin | 全部权限 | 系统管理员 |
| admin | 除系统设置外的全部权限 | 租户管理员 |
| channel-admin | 渠道管理权限 | 渠道管理员 |
| editor | 内容编辑权限 | 内容编辑 |
| viewer | 只读权限 | 查看者 |

### 2.3 权限说明

- 系统会根据用户角色自动过滤可访问的菜单和操作
- 无权限的菜单会自动隐藏
- 无权限的操作会返回 403 错误

## 4. 多租户管理

### 4.1 功能概述

多租户管理用于管理系统中的多个租户（站点），每个租户拥有独立的渠道、课程和配置。

### 4.2 创建租户

**操作步骤**：

1. 点击左侧菜单「多租户管理」→「租户列表」
2. 点击「新建租户」按钮
3. 填写租户信息：
   - **租户名称**：站点名称
   - **域名**：站点访问域名
   - **描述**：站点描述（可选）
   - **ICP备案号**：网站备案号（可选）
4. 点击「保存并继续」按钮
5. 在下方配置三方登录信息（可选）：
   - 微信配置
   - 其他第三方登录配置
6. 点击「保存配置」按钮

### 4.3 编辑租户

**操作步骤**：

1. 在租户列表中点击要编辑的租户
2. 修改租户信息
3. 点击「保存并返回」按钮

### 4.4 删除租户

**操作步骤**：

1. 在租户列表中找到要删除的租户
2. 点击「删除」按钮
3. 在确认对话框中点击「确定」

> **注意**：删除租户会同时删除关联的站点配置和三方配置

### 4.5 渠道关联

**操作步骤**：

1. 进入租户详情页
2. 在「渠道配置」区域选择要关联的渠道
3. 点击「保存」按钮

> **提示**：一个租户可以关联多个渠道

## 5. 渠道管理

### 5.1 功能概述

渠道管理用于管理系统的渠道层级结构，支持多级渠道、成员管理和邀请码机制。

### 5.2 渠道层级

```
平台根渠道
├── 省级渠道
│   ├── 市级渠道
│   │   └── 个人渠道
│   └── 市级渠道
└── 省级渠道
    └── ...
```

### 5.3 创建渠道

**操作步骤**：

1. 点击左侧菜单「渠道管理」→「渠道列表」
2. 点击「新建渠道」按钮
3. 填写渠道信息：
   - **渠道名称**：必填
   - **描述**：可选
   - **层级**：root/national/provincial/city/personal
   - **父渠道**：选择上级渠道
4. 点击「保存」按钮

### 5.4 查看渠道网络

**操作步骤**：

1. 在渠道列表中找到要查看的渠道
2. 点击「网络」按钮
3. 在弹出的窗口中查看渠道树结构

### 5.5 管理渠道成员

**操作步骤**：

1. 在渠道列表中找到要管理的渠道
2. 点击「成员」按钮
3. 查看成员列表
4. 点击「邀请成员」添加新成员
5. 点击「移除成员」删除成员

### 5.6 生成邀请码

**操作步骤**：

1. 进入渠道详情页
2. 在「邀请码」区域点击「生成邀请码」
3. 复制邀请码分享给他人

课程管理用于管理系统中的课程内容，包括课程、课时、分类、标签和知识点。

2. 点击「新建标签」按钮
3. 填写标签名称
4. 点击「保存」按钮

### 6.6 知识点管理

**操作步骤**：

1. 点击左侧菜单「课程管理」→「知识点」
2. 点击「新建知识点」按钮

## 7. 题库管理

### 7.1 功能概述

题库管理用于管理系统中的题目，支持多种题型和难度级别。

### 7.2 创建题目

**操作步骤**：

1. 点击左侧菜单「题库管理」→「题目列表」
2. 点击「新建题目」按钮
3. 填写题目信息：
   - **题目内容**：必填
   - **题目类型**：single-choice/multiple-choice/true-false/fill-blank/essay
   - **难度等级**：easy/medium/hard
   - **分数**：题目分值
   - **正确答案**：必填
   - **选项**：选择题需要填写选项
   - **解释说明**：题目解析（可选）
4. 点击「保存」按钮

### 7.3 批量导入题目

**操作步骤**：

1. 点击左侧菜单「题库管理」→「批量导入」
2. 下载导入模板
3. 按照模板格式填写题目数据
4. 上传填写好的文件
5. 点击「导入」按钮

### 7.4 考试管理

**操作步骤**：

1. 点击左侧菜单「题库管理」→「考试管理」
2. 点击「新建考试」按钮
3. 填写考试信息：
   - **考试名称**：必填
   - **描述**：考试说明
   - **题目来源**：从题库中选择题目
   - **时间限制**：考试时长
   - **及格分数**：及格线
4. 点击「保存」按钮

### 7.5 查看答题记录

**操作步骤**：

1. 点击左侧菜单「题库管理」→「答题记录」
2. 选择要查看的记录
3. 查看答题详情和得分

## 8. 积分管理

### 8.1 功能概述

积分管理用于管理系统的积分体系，包括积分类型、规则、记录和兑换。

### 8.2 积分类型管理

**操作步骤**：

1. 点击左侧菜单「积分管理」→「积分类型」
2. 点击「新建积分类型」按钮
3. 填写积分类型信息：
   - **类型代码**：唯一标识，如 "study_points"
   - **类型名称**：显示名称，如 "学习积分"
   - **描述**：类型说明
   - **是否启用**：默认启用
   - **是否可过期**：默认启用
   - **过期天数**：默认 365 天
4. 点击「保存」按钮

### 8.3 积分规则管理

**操作步骤**：

1. 点击左侧菜单「积分管理」→「积分规则」
2. 点击「新建规则」按钮
3. 填写规则信息：
   - **积分类型**：选择积分类型
   - **积分数**：奖励积分数量
   - **条件**：触发条件（可选）
   - **限制**：使用限制（可选）
   - **有效期**：规则生效时间（可选）
4. 点击「保存」按钮

### 8.4 积分记录查看

**操作步骤**：

1. 点击左侧菜单「积分管理」→「积分记录」
2. 使用筛选条件查找记录：
   - 用户ID
   - 积分类型
   - 时间范围
3. 查看积分变更记录

### 8.5 积分兑换管理

**操作步骤**：

1. 点击左侧菜单「积分管理」→「兑换管理」
2. 点击「新建兑换商品」按钮
3. 填写商品信息：
   - **商品名称**：必填
   - **描述**：商品说明
   - **所需积分**：兑换所需积分
   - **库存**：商品数量
4. 点击「保存」按钮

### 8.6 积分统计

**操作步骤**：

1. 点击左侧菜单「积分管理」→「统计报表」
2. 查看积分发放、消费和余额统计
3. 使用时间筛选器查看不同时间段的数据

## 12. 常见问题

### 12.1 登录失败

**问题**：输入用户名和密码后无法登录

**排查步骤**：

1. 检查用户名和密码是否正确
2. 检查网络连接是否正常
3. 检查服务器是否正常运行
4. 联系系统管理员重置密码

### 12.2 页面空白

**问题**：登录后页面显示空白

**排查步骤**：

1. 刷新页面
2. 清除浏览器缓存
3. 检查浏览器版本是否符合要求
4. 检查控制台是否有错误信息

### 12.3 权限不足

**问题**：无法访问某些菜单或执行某些操作

**排查步骤**：

1. 检查当前用户角色
2. 联系管理员获取更高权限
3. 确认是否需要先完成其他操作

### 12.4 文件上传失败

**问题**：上传图片或文件失败

**排查步骤**：

1. 检查文件大小是否超过限制
2. 检查文件格式是否支持
3. 检查网络连接是否正常
4. 联系管理员检查服务器存储配置

### 12.5 数据不显示

**问题**：页面不显示数据

**排查步骤**：

1. 检查筛选条件是否正确
2. 检查是否有权限查看该数据
3. 检查网络连接是否正常
4. 检查服务器是否正常运行
