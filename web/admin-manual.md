## 1. 系统概述

### 1.1 系统架构

本系统是基于 Strapi + UniApp 构建的多租户管理后台，主要功能模块包括：

```
后台管理系统
├── 多租户管理 — 创建/编辑/删除租户，配置站点信息、三方登录、模板样式
├── 渠道管理 — 渠道树结构，成员管理，邀请码，渠道网络查看
├── 课程管理 — 课程/课时/分类/标签/知识点管理，渠道权限控制
├── 题库管理 — 题目管理，答题记录，考试管理，批量导入
├── 积分管理 — 积分类型/规则/记录/兑换管理，统计报表
├── 系统管理 — 用户/角色/权限/日志管理
├── 媒体管理 — 文件上传，图片库管理
├── 第三方配置 — 微信登录/分享配置，支付宝/抖音登录
└── 仪表盘 — 数据统计概览
```

### 1.2 浏览器要求

| 浏览器 | 最低版本 | 说明 |
|--------|----------|------|
| Chrome | 90+ | 推荐 |
| Firefox | 88+ | |
| Edge | 90+ | |

### 1.3 访问地址

- **开发环境**：http://localhost:1337/admin
- **生产环境**：http://你的域名/admin

### 1.4 角色权限说明

| 角色 | 权限范围 | 适用场景 |
|------|----------|----------|
| super-admin | 全部权限 | 系统管理员 |
| admin | 除系统设置外的全部权限 | 租户管理员 |
| channel-admin | 渠道管理权限 | 渠道管理员 |
| editor | 内容编辑权限 | 内容编辑 |
| viewer | 只读权限 | 查看者 |

## 2. 登录与权限

### 2.1 登录流程

1. 打开浏览器，访问后台地址
2. 在登录页面输入用户名和密码
3. 点击「登录」按钮

**默认账号**：
- 用户名：admin
- 密码：首次启动时设置

### 2.2 权限说明

- 系统会根据用户角色自动过滤可访问的菜单和操作
- 无权限的菜单会自动隐藏
- 无权限的操作会返回 403 错误
- 管理员用户拥有全部渠道权限

## 4. 多租户管理

### 4.1 功能概述

多租户管理用于管理系统中的多个租户（站点），每个租户拥有独立的渠道、课程和配置。支持：
- 创建/编辑/删除租户
- 配置站点基本信息（名称、域名、Logo等）
- 设置SEO信息
- 配置分享参数
- 开启/关闭功能开关
- 设置认证模式（本地登录/三方登录/SSO）
- 关联渠道
- 配置三方登录（微信/支付宝/抖音）
- 设置模板样式和主题色

### 4.2 创建租户

**操作步骤**：

1. 点击左侧菜单「多租户管理」→「租户列表」
2. 点击「新建租户」按钮
3. 填写租户基本信息：

**基本信息字段说明：**

| 字段名称 | 必填 | 说明 | 示例 |
|----------|------|------|------|
| 租户名称 | * | 站点名称，显示在页面标题和分享中 | 我的教育平台 |
| 域名 | * | 站点访问域名，用于区分不同租户 | example.com |
| 租户描述 | | 站点描述信息 | 专注于职业技能培训的在线教育平台 |
| ICP备案号 | | 网站备案号，用于合规展示 | 京ICP备12345678号 |
| 客服链接 | | 客服入口链接，如企业微信 | https://work.weixin.qq.com/... |

4. 设置站点标识：

**站点标识字段说明：**

| 字段名称 | 必填 | 说明 | 建议尺寸 |
|----------|------|------|----------|
| 站点 Logo | | 站点Logo图片，显示在页面顶部 | 200x200px |
| Favicon | | 浏览器标签图标 | 32x32px |

5. 配置SEO设置：

**SEO设置字段说明：**

| 字段名称 | 必填 | 说明 | 示例 |
|----------|------|------|------|
| SEO关键词 | | 搜索引擎关键词，多个用逗号分隔 | 在线教育,职业培训,技能学习 |
| SEO描述 | | 搜索引擎展示的描述文字 | 专业的在线职业技能培训平台 |
| 腾讯地图Key | | 腾讯位置服务API Key | XXXXXXXX |

6. 配置分享设置：

**分享设置字段说明：**

| 字段名称 | 必填 | 说明 | 示例 |
|----------|------|------|------|
| 分享标题 | | 转发朋友圈时的标题 | 快来学习这门课程！ |
| 分享描述 | | 转发朋友圈时的描述 | 专业讲师授课，助你快速成长 |
| 分享封面图 | | 分享时显示的封面图片 | 推荐尺寸 500x400px |
| 分享路径 | | 分享链接指向的页面路径 | /pages/index/index |

7. 设置功能开关：

**功能开关说明：**

| 开关名称 | 默认值 | 说明 |
|----------|--------|------|
| SSO登录 | 关闭 | 启用单点登录功能 |
| 积分系统 | 开启 | 启用积分奖励系统 |
| 题库管理 | 开启 | 启用题库和考试功能 |
| 课程管理 | 开启 | 启用课程管理功能 |
| 渠道管理 | 开启 | 启用渠道管理功能 |
| 三方登录 | 开启 | 启用微信/支付宝/抖音登录 |
| OSS存储 | 关闭 | 启用阿里云OSS存储 |

8. 配置认证模式：

**认证模式说明：**

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 本地登录 | 使用账号密码或手机验证码登录 | 独立站点，无需第三方登录 |
| 三方登录 | 使用微信/支付宝/抖音登录 | 需要社交账号登录 |
| SSO单点登录 | 使用企业SSO系统登录 | 企业内部集成 |

**三方登录平台选择（认证模式为"三方登录"时显示）：**

| 平台 | 说明 |
|------|------|
| 微信公众号 | 微信网页授权登录 |
| 微信小程序 | 微信小程序登录 |
| 微信开放平台 | 微信开放平台登录 |
| 支付宝 | 支付宝登录 |
| 抖音 | 抖音登录 |

**SSO配置（认证模式为"SSO"时显示）：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| SSO登录地址 | * | SSO登录页面URL |

**注册设置：**

| 字段名称 | 默认值 | 说明 |
|----------|--------|------|
| 允许注册 | 关闭 | 是否允许用户自主注册 |
| 必填邀请码 | 关闭 | 注册时是否必须填写邀请码 |

9. 配置渠道（**必选**）：

**渠道配置说明：**

| 设置项 | 说明 |
|--------|------|
| 是否允许跨渠道 | 开启后用户可见跨渠道课程/分类，关闭后仅展示站点渠道数据 |
| 关联渠道 | 选择租户关联的渠道，只能选择你有权限的渠道 |

**操作步骤：**
- 点击「+ 添加渠道」按钮
- 在弹出的渠道选择器中选择要关联的渠道（可多选）
- 点击渠道名称左侧的复选框进行选择/取消选择
- 点击「确定」按钮确认选择

10. 点击「保存并继续」按钮保存租户信息

**注意事项：**
- 租户名称和域名为必填项，必须填写
- 渠道为必选项，必须至少选择一个渠道
- 保存后会自动生成租户的documentId，用于后续配置
- 保存后页面会刷新，进入编辑模式

11. 配置三方登录（保存租户后）：

**操作步骤：**
- 在「三方登录配置」区域点击「+ 添加配置」
- 填写配置信息：

**三方登录配置字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 配置名称 | * | 配置的显示名称 |
| 平台 | * | 选择平台：微信、支付宝、抖音 |
| 应用类型 | * | 选择应用类型：公众号、小程序、开放平台等 |
| App ID/AppID/Client Key | * | 对应平台的应用ID |
| App Secret/应用私钥/Client Secret | * | 对应平台的应用密钥 |
| 商户号 | | 支付宝平台需要填写 |
| Token | | 微信平台需要填写 |
| 启用状态 | | 是否启用该配置 |

- 点击「保存」按钮保存配置
- 配置会显示在三方登录配置列表中，可进行编辑和删除

12. 配置模板样式：

**模板样式字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 预设模板 | | 选择预设的站点模板 |
| 主题色 | | 站点主色调，影响按钮、导航栏等 |
| 辅助色 | | 辅助颜色，用于强调和次要元素 |
| 导航样式 | | 默认、渐变、自定义 |
| tabBar颜色 | | 底部导航栏背景色 |
| tabBar激活色 | | 底部导航栏激活状态颜色 |

### 4.3 编辑租户

**操作步骤**：

1. 在租户列表中点击要编辑的租户名称
2. 修改租户信息（参考创建租户的字段说明）
3. 如需修改三方登录配置：
   - 点击配置项右侧的「编辑」按钮
   - 修改配置信息
   - 点击「保存」按钮
4. 如需删除三方登录配置：
   - 点击配置项右侧的「删除」按钮
   - 在确认对话框中点击「确定」
5. 点击「保存」按钮保存修改，或点击「保存并返回」按钮保存并返回列表

### 4.4 删除租户

**操作步骤**：

1. 在租户列表中找到要删除的租户
2. 点击「删除」按钮
3. 在确认对话框中点击「确定」

> **注意**：删除租户会同时删除关联的站点配置和三方配置，此操作不可恢复，请谨慎操作。

### 4.5 常见问题与错误提示

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 提示"请填写租户名称和域名" | 租户名称或域名未填写 | 填写租户名称和域名 |
| 提示"请选择至少一个渠道" | 未选择关联渠道 | 点击「+ 添加渠道」选择渠道 |
| 提示"请先保存租户信息" | 在新建租户时未保存就尝试添加三方配置 | 先点击「保存并继续」保存租户 |
| 提示"请填写SSO登录地址" | 认证模式为SSO但未填写SSO地址 | 填写SSO登录地址 |
| 三方配置列表不显示 | 新建租户后未刷新页面 | 保存租户后等待页面自动刷新 |

## 5. 渠道管理

### 5.1 功能概述

渠道管理用于管理系统的渠道层级结构，支持多级渠道、成员管理和邀请码机制。

### 5.2 渠道层级

```
平台根渠道
├── 省级渠道
│   ├── 市级渠道
│   │   └── 个人渠道
│   └── 市级渠道
└── 省级渠道
    └── ...
```

**渠道层级说明：**

| 层级代码 | 显示名称 | 说明 |
|----------|----------|------|
| root | 根渠道 | 平台级渠道 |
| national | 全国 | 国家级渠道 |
| provincial | 省级 | 省级渠道 |
| city | 城市 | 市级渠道 |
| county | 区县 | 区县级渠道 |
| local | 本地 | 本地渠道 |
| store | 门店 | 门店级渠道 |
| core | 核心渠道 | 核心合作渠道 |
| senior | 高级渠道 | 高级渠道 |
| global | 全球渠道 | 全球渠道 |
| authorized | 授权渠道 | 授权渠道 |
| official | 官方渠道 | 官方渠道 |
| partner | 合作伙伴 | 合作伙伴渠道 |
| agent | 代理渠道 | 代理商渠道 |

### 5.3 创建渠道

**操作步骤**：

1. 点击左侧菜单「渠道管理」→「渠道列表」
2. 点击「+ 新增」按钮或右下角的「+」悬浮按钮
3. 填写渠道信息：

**渠道信息字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 渠道名称 | * | 渠道的显示名称 |
| 代码 | | 渠道的唯一代码（系统自动生成） |
| 描述 | | 渠道的描述信息 |
| 层级 | * | 选择渠道层级（root/national/provincial/city等） |
| 父渠道 | | 选择上级渠道（可选，创建子渠道时必填） |

4. 点击「保存」按钮

### 5.4 查看渠道列表

**操作步骤**：

1. 点击左侧菜单「渠道管理」→「渠道列表」
2. 在列表中查看所有渠道信息

**列表字段说明：**

| 字段名称 | 说明 |
|----------|------|
| 渠道名称 | 渠道的显示名称 |
| 代码 | 渠道的唯一代码 |
| 描述 | 渠道的描述信息 |
| 状态 | 启用/禁用 |
| 层级 | 渠道层级 |
| 上级 | 上级渠道名称 |

**筛选功能：**

| 筛选条件 | 说明 |
|----------|------|
| 搜索框 | 按渠道名称搜索 |
| 层级筛选 | 按渠道层级筛选 |
| 状态筛选 | 按启用/禁用状态筛选 |

### 5.5 查看渠道网络

**操作步骤**：

1. 在渠道列表页面点击顶部的「网络」按钮
2. 在弹出的窗口中查看渠道树结构
3. 可以展开/折叠各级渠道查看完整层级

### 5.6 管理渠道成员

**操作步骤**：

1. 在渠道列表中找到要管理的渠道
2. 点击「成员」按钮
3. 查看成员列表
4. 点击「邀请成员」添加新成员
5. 点击「移除成员」删除成员

### 5.7 编辑渠道

**操作步骤**：

1. 在渠道列表中找到要编辑的渠道
2. 点击「编辑」按钮
3. 修改渠道信息
4. 点击「保存」按钮

### 5.8 删除渠道

**操作步骤**：

1. 在渠道列表中找到要删除的渠道
2. 点击「删除」按钮
3. 在确认对话框中点击「确定」

> **注意**：删除渠道会级联删除所有子渠道和成员，此操作不可恢复，请谨慎操作。

### 5.9 生成邀请码

**操作步骤**：

1. 进入渠道详情页
2. 在「邀请码」区域点击「生成邀请码」
3. 复制邀请码分享给他人

### 5.10 常见问题与错误提示

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 无法创建子渠道 | 未选择父渠道 | 在创建渠道时选择父渠道 |
| 删除渠道失败 | 渠道下有子渠道或成员 | 先删除子渠道和成员，再删除当前渠道 |
| 搜索不到渠道 | 关键词输入错误 | 检查搜索关键词是否正确 |

## 6. 课程管理

### 6.1 功能概述

课程管理用于管理系统中的课程内容，包括课程、课时、分类、标签和知识点。支持：
- 创建/编辑/删除课程
- 配置课程基本信息
- 设置课程价格（免费/付费/折扣）
- 关联课程分类和标签
- 关联知识点
- 设置渠道权限范围
- 配置积分奖励
- 设置课程时间和状态

### 6.2 创建课程

**操作步骤**：

1. 点击左侧菜单「课程管理」→「课程列表」
2. 点击「+ 新增课程」按钮
3. 填写课程基本信息：

**基本信息字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 课程名称 | * | 课程的显示名称 |
| 课程描述 | | 课程的详细描述 |
| 作者 | | 课程作者名称 |

4. 上传媒体资源：

**媒体资源字段说明：**

| 字段名称 | 必填 | 说明 | 建议尺寸 |
|----------|------|------|----------|
| 封面图 | | 课程封面图片 | 800x600px |
| 缩略图 | | 课程缩略图 | 200x200px |

**上传操作步骤：**
- 点击上传区域
- 在弹出的媒体选择器中选择图片
- 图片会自动上传并显示预览

5. 设置课程价格：

**价格设置字段说明：**

| 字段名称 | 必填 | 说明 |
|----------|------|------|
| 免费课程 | | 开启后课程免费 |

## 7. 网站内容管理

### 7.1 功能概述

网站内容管理用于管理面向官网公开展示的 7 类内容（Content Type，简称 CT），所有 CT 遵循统一的状态流转和操作模式。支持：

- 创建/编辑/删除内容
- 统一的状态流转：draft（草稿）→ published（已发布）→ archived（已下架）
- 列表页搜索 + 状态筛选 + 分页
- 编辑页基本信息 + 内容区 + 扩展区结构
- JSON 字段（features/specifications/scenarios/results/steps/materials）容错解析

**CT 列表：**

| CT | 名称 | 主字段 | 说明 |
|----|------|--------|------|
| article | 资讯文章 | title | 公司新闻、行业动态、活动公告 |
| product | 产品 | name | 产品介绍、特性规格、应用场景 |

### 7.2 通用操作流程

**列表页操作：**

### 7.10 JSON 字段编辑说明

features、specifications、scenarios、results、steps、materials 等字段使用 textarea 编辑 JSON 内容。

**输入规范：**

| 规则 | 说明 |
|------|------|
| 字符串 | 必须使用双引号 `"`，不能使用单引号 |
| 数组 | 使用方括号 `[]`，元素用逗号分隔 |
| 对象 | 使用花括号 `{}`，键值对用冒号分隔 |
| 布尔值 | 使用 `true` 或 `false`（小写） |
| 数字 | 直接写数字，无需引号 |

**示例：**

features（数组）：

```json
["快速搭建", "多端适配", "权限管控"]
```

specifications（对象）：

```json
{"version": "2.0", "size": "15MB", "platform": "Web/Android/iOS"}
```

> **注意**：系统使用 `safeParse` 容错解析，JSON 解析失败时降级为空数组 `[]`，不会阻断保存，但内容会丢失。请保存前检查 JSON 语法。

### 7.11 常见问题与错误提示

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| JSON 字段保存失败 | JSON 语法错误（单引号、缺少逗号、括号不匹配等） | 检查 JSON 语法，使用双引号和正确的括号 |
| 发布后官网看不到内容 | status 未设置为 published | 在编辑页将状态改为「已发布」并保存 |
| 列表页或编辑页按钮不显示 | 当前用户角色权限不足 | 联系系统管理员分配相应 CT 的操作权限 |
| 上传封面图失败 | 文件过大或格式不支持 | 参考「媒体管理」章节的文件要求 |
| slug 重复导致保存失败 | 同一 CT 内 slug 必须唯一 | 修改 slug 或使用系统建议值 |

## 13. 常见问题

### 13.1 登录失败

**问题**：输入用户名和密码后无法登录

**排查步骤**：

1. 检查用户名和密码是否正确
2. 检查网络连接是否正常
3. 检查服务器是否正常运行
4. 联系系统管理员重置密码

### 13.2 页面空白

**问题**：登录后页面显示空白

**排查步骤**：

1. 刷新页面
2. 清除浏览器缓存
3. 检查浏览器版本是否符合要求
4. 检查控制台是否有错误信息

### 13.3 权限不足

**问题**：无法访问某些菜单或执行某些操作

**排查步骤**：

1. 检查当前用户角色
2. 联系管理员获取更高权限
3. 确认是否需要先完成其他操作

### 13.4 文件上传失败

**问题**：上传图片或文件失败

**排查步骤**：

1. 检查文件大小是否超过限制
2. 检查文件格式是否支持
3. 检查网络连接是否正常
4. 联系管理员检查服务器存储配置

### 13.5 数据不显示

**问题**：页面不显示数据

**排查步骤**：

1. 检查筛选条件是否正确
2. 检查是否有权限查看该数据
3. 检查网络连接是否正常
4. 检查服务器是否正常运行

### 13.6 租户保存失败

**问题**：创建或编辑租户时保存失败

**排查步骤**：

1. 检查租户名称和域名是否填写
2. 检查是否选择了至少一个渠道
3. 检查表单中的必填项是否都已填写
4. 检查网络连接是否正常

### 13.7 课程发布后不可见

**问题**：课程发布后在前端不可见

**排查步骤**：

1. 检查课程状态是否为「已发布」
2. 检查课程的渠道范围设置是否正确
3. 检查是否设置了正确的积分归属渠道
4. 检查课程的时间设置是否在有效期内

### 13.8 渠道无法删除

**问题**：尝试删除渠道时失败

**排查步骤**：

1. 检查渠道下是否有子渠道，先删除子渠道
2. 检查渠道下是否有成员，先移除成员
3. 检查渠道是否被课程或其他资源引用
